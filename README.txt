DOCTOR PHOTOS
=============
Put each doctor's photo in this folder, named after the doctor's ID:

    1.jpg   -> doctor with ID 1
    2.jpg   -> doctor with ID 2

(The ID is shown in the first column of the "All Doctors" table on the Admin page.)

Tips
- Use .jpg only. A square or 4:3 photo works best (e.g. 800 x 600 px).
- Keep each file under 150 KB so the site stays fast.
- If a doctor has no photo, a clean placeholder icon is shown automatically.
- Only use photos you have permission to use (the doctor's own photo or a licensed image).
