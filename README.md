# 🏥 SehatConnect Peshawar

Online doctor appointment booking system for clinics in Peshawar, Pakistan.

## Features
- 🔍 Search doctors by name, specialty, area
- 📅 Online appointment booking
- ⏱️ 2-minute auto-confirm system
- 💳 Manual JazzCash/EasyPaisa payment verification
- 👥 Multi-admin support
- 📊 Traffic analytics dashboard
- 💾 Auto-backup and data recovery
- 📋 Audit log for admin actions

## Tech Stack
- Python 3.13 + Flask
- HTML, CSS, JavaScript
- JSON file storage
- ngrok tunnel
