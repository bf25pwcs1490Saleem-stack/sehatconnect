📌 SETUP FOR NEW TEAM MEMBER
----------------------------------------------------------
1. Install Python: https://python.org/downloads
   ⚠️ Check "Add Python to PATH" during install

2. Install Git: https://git-scm.com/download/win

3. Clone the project:
   cd %USERPROFILE%\Desktop
   git clone https://github.com/bf25pwcs1490Saleem-stack/sehatconnect.git
   cd sehatconnect

4. Install dependencies:
   pip install flask

5. Create empty data files:
   echo [] > doctors.json
   echo [] > appointments.json
   echo {} > analytics.json
   echo [] > audit_log.json

6. Run:
   python app.py

7. Open: http://127.0.0.1:5000
