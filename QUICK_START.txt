SEHATCONNECT — QUICK START (For Team Members)
==========================================================

🔥 START THE PROJECT
----------------------------------------------------------
1. Double-click: go_live.bat
   OR open CMD and run:
   cd %USERPROFILE%\Desktop\sehatconnect
   python app.py

2. Open browser: http://127.0.0.1:5000

3. Admin login: http://127.0.0.1:5000/admin/login
   Username: member1
   Password: (ask team lead)

🔥 STOP THE PROJECT
----------------------------------------------------------
Press Ctrl + C in the CMD window

🔥 PUSH YOUR CHANGES
----------------------------------------------------------
git pull              (get latest first)
git add .
git commit -m "What I changed"
git push

🔥 GET OTHERS' CHANGES
----------------------------------------------------------
git pull

🔥 IF SOMETHING BREAKS
----------------------------------------------------------
Check:
- Is Flask running? (look for "Running on 0.0.0.0:5000")
- Is port 5000 free? (close other CMD windows)
- Are data files there? (dir doctors.json)
- Git error? Run: git status

🔥 IMPORTANT RULES
----------------------------------------------------------
